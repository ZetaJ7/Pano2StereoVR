## 约定

- 翻转：数据集 ERP 的 `lon=((u+.5)/W−.5)·2π`、`ray=[−sin lon cos lat, …]`，图像右侧对应相机左侧。分析与预览时每帧都做水平翻转 `[:, ::-1]`，翻转后文字可正读（cafe 墙上的 “ATELIER / COFFEE”）。主会话用 Blender 原生渲染核实过：数据集 target 就是原生 ERP 的水平翻转（PSNR 65 dB，深度一致），原生 ERP 的图像右侧对应相机右侧。**本文所有 yaw 都以翻转后为准：content yaw 向右为正，0 为 ERP 中心。** 渲染时必须产出同一朝向。
- 位姿：`rig_camera_to_world` 只含偏航（已核对，俯仰与横滚为 0）。ψ = atan2(−R[0,2], R[2,2])，即 `yaw_rotation` 约定，+ψ 表示向右（+X）转。
- 固定朝向 H（与 `yaw_rotation` 同一约定）：稳定后图像为 S = roll(I_flip, round((ψ−H)/360·W))。content yaw c = 世界方位 − H。已在 4 段 curved_yaw 上核对符号：+1 的帧间差最小，与 −1 或不平移相比，深度差约小一半。
- H 有三种取法：`mean` = 窗口内 ψ 的圆周均值（建议用这个，与 Replica near_B/C/D 相同）；`start` = ψ(f0)；`travel` = 窗口净位移方向。固定朝向会去掉原轨迹 28–151° 的偏航。
- 窗口：12 s，即源帧 f0..f0+359（30 fps）。筛选时 t0 = f0/30 ∈ {0, 0.5, …, 3.0} s，建议片段的起点不超过 2.9 s。25 fps 重渲染时取 t0 + k/25（k = 0..299）。
- 近物：定义同 `e5_object_measure.py`：0.5 ≤ z ≤ 2 m，且 7×7 邻域（3.5°）最大深度 ≥ 1.3z；15° 圆，pitch 0；720×360 分辨率。室外天空（深度 0）只在最大值滤波中按 1000 m 计（视为更远的背景），本身不算物体。
- 持续性：近物比例 ≥ 0.03 的采样占比（10 fps）。“最长”指连续 ≥ 0.03 的最长时长。
- 前方：content yaw ±30°、pitch ±20°，D = 光线深度中位数。
