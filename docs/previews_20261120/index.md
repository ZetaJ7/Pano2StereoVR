# Replica 片段预览与前方视野数据（2026-11-20）

由 173 `E5_stimuli/tools_replica/e5_forward_view.py`、`e5_preview_sheet.py` 生成；原始数据（逐帧序列、全部阈值）在同目录的 `forward_view_<片段>.json`（173：`E5_stimuli/previews_replica/`）。所有数字只供挑选，没有设定任何阈值或取舍规则。

## 约定

- content yaw：播放器把 content yaw 0 放在 ERP 中心；向右为正。pitch 向上为正。
- offset 0：去转向后以第 0 帧的朝向为前方（`yaw_stabilize.py` 的做法，即目前的样片）。新生成的 4 条序列按固定朝向（第 0 帧路径朝向）渲染，等同于 offset 0。
- offset M：在 offset 0 的基础上整段再加一个固定的整像素水平平移，把 12 s 内路径朝向的圆周均值放到 content yaw 0。表中“均值朝向”是这个均值在 offset 0 画面里的 content yaw，“平移”是 5768 宽下的像素数（负 = 向左滚动）。
- 前方窗口：content yaw ±30°、pitch ±20°。D = 窗口内光线深度的中位数（m），逐帧；C = 窗口内 1 s 画面变化（与 25 帧前的灰度平均绝对差，0–255），从第 25 帧起。
- 15° 圆深度：以 (content yaw, pitch 0) 为中心、半径 15° 内光线深度的中位数，12 个候选方向（每 30°），offset 0 画面。
- 静止：轨迹中相机位置不变的帧（walk_retarget 的原地转向段）。去转向或固定朝向后这些帧的画面完全静止。
- 深度来源：已有 8 条用 StdTest 1080 的 `depth_ray`（与 run_0009 4K 同一轨迹）；新 4 条用 4K 渲染的 habitat 立方体面平面深度换算成光线距离。分析分辨率 1092×546。
