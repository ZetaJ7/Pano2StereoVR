## 5. 分析（第一位被试之前冻结）

| 项目 | 内容 |
| --- | --- |
| 计分 | 程序现有 SSQ：16 项，每项 0–3，ITU-T P.919 §7.2.1 的 N、O、D 与总分 TS（`analyze_study.py` 的 `ssq_scores`） |
| 每次会话的指标 | ΔTS = TS(`S_post`) − TS(`S_pre`) |
| 主要结果（用户已定） | Mono 与 Ours 的 ΔTS 有无显著差异，双尾，α = 0.05。按顺序组校正时期效应：每人 c = 第一次会话 ΔTS − 第二次会话 ΔTS，比较两个顺序组；Ours 减 Mono 的估计为两组 c 均值之差的一半（符号按顺序组取）。两组比较用置换检验（重排顺序组标签，以均值差为统计量，保留 0 值）（用户已定） |
| 常规报告（用户已定） | 差值的均值、中位数与置信区间；时期效应的估计 |
| 次要结果（用户已定） | 每人配对差 D = ΔTS(Ours) − ΔTS(Mono) 的双尾 Wilcoxon 符号秩检验 |
| 事先写明的次要指标（用户已定） | SSQ 眼动分量 O 的同样比较；每段“舒适度”评分的 Ours 减 Mono |
| 描述 | N、D 两个分量；两种条件的前测是否相当；单次会话 ΔTS 为 0 的人数、配对差为 0 的人数，Ours 高于、低于、等于 Mono 的人数；每段三项评分；是否参加过实验 1 与相隔天数；两组之间 c 的差别作为残留影响只描述，不做“先检验再选分析”的两步法 |
| 中途停止（用户已定） | 不剔除，用停止时填的后测计入；按条件报告停止人数与已看段数 |
| 判定与行文（用户已定） | 不预设可接受的增幅，不做等效或非劣效检验；只报告有无显著差异。不显著时写“未检出显著差异”，并给出置信区间 |
| 程序 | `analyze_study.py` 按单次会话设计，需另写一个小脚本，把同一被试的两次会话配对，计算 c、D 与时期效应；用模拟数据跑通后再冻结 |

20 人的大致功效（配对 t 近似，双尾，α = 0.05；Wilcoxon 略低）：d_z = 0.5 时 0.56，0.7 时 0.84，0.8 时 0.92。核查会话的模拟：按顺序组校正的做法在没有时期效应时功效约低 3 个百分点，第二次会话整体偏低时基本不受影响；0 值多时功效下降（一半会话为 0 时，d_z = 0.5 的功效由约 0.55 降到约 0.44）。
