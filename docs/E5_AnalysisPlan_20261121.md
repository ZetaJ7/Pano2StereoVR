# 主观实验（E5）分析方案（2026-11-21 起草，待用户过目后在第一位正式被试之前冻结）

用途：把分析程序 `D:\WorkSpace\Pano2StereoVR_study\StudyTools\analyze_study.py` 里尚未设定的判定项全部定下来，写成 `analysis_config.json`，在第一位正式被试之前提交 git 留时间戳。程序本身不需要改，所有判定项都从配置读取。

用户已定（11-21 晚）：计划 30 人，40 份试次清单中的后 10 份备用；主比较为 Ours 减 Mono 的三项评分，双尾 Wilcoxon 符号秩检验，六项检验做 Holm 校正，主分析不筛除被试。下文其余各项是 Claude 的建议，以用户过目后的版本为准。

## 1. 进入分析的数据

| 项目 | 取值 | 配置键 |
| --- | --- | --- |
| 会话模式 | 只分析正式会话，QA 与预实验会话不进入 | `session_modes: ["formal"]` |
| 会话状态 | 只取完成的会话；中止的会话列在报告里，不进入结果 | 程序固定行为 |
| 样本量 | 30 人完成即停止；中止或按规则排除的被试用备用清单（P31 起）补足 | 操作规定 |
| 中途查看 | 采集期间不查看推断性结果；只看数据完整性、丢帧与时长 | 操作规定 |
| 自报视力异常 | 排除（与招募条件一致） | `exclude_self_reported_vision: true` |
| 立体视粗筛 | 原则：只排除在最大视差档也不能通过的被试；具体档位与通过次数在周一上午预实验后、正式采集前写入 | `stereo_pass_rule`（预实验后填） |
| 试次级排除：播放丢帧 | 丢帧比例超过 5% 的试次不进入分析 | `dropped_frame_fraction_threshold: 0.05` |
| 试次级排除：头部偏离 | 不另设阈值。第二部分程序在线上已对头部偏离做中断重播，分析时只报告偏离分布 | `head_deviation_threshold_deg: null` |

## 2. 主分析（确认性，六项检验一族，Holm 校正，双尾，α = 0.05）

| 编号 | 问题 | 统计量（每位被试一个值） | 检验 |
| --- | --- | --- | --- |
| P1 | Ours 的立体感是否不同于 Mono | 第一部分 9 个正式片段上"立体感"评分的 Ours 减 Mono，对片段取平均 | Wilcoxon 符号秩，对 0 |
| P2 | 观看舒适度 | 同上，"观看舒适度" | 同上 |
| P3 | 画面瑕疵 | 同上，"画面瑕疵" | 同上 |
| P4a | PA 与 PAw 能否被分辨 | 第二部分的 d′，真实配对为信号、相同配对为噪声，对数线性校正 | Wilcoxon 符号秩，对 0 |
| P4b | 对 PAw 的偏好 | 真实配对上偏好分（−3 到 +3，正向为偏向 PAw）的均值，答"无区别"的试次记 0 | Wilcoxon 符号秩，对 0 |
| P5 | 全程前后的晕动症状变化 | SSQ 总分，结束时减开始前 | Wilcoxon 符号秩，对 0 |

- 评分取最终评分（组末改分之后）。
- 效应量：秩二列相关 r；中位数的 bootstrap 95% 置信区间（10000 次，种子 20261115）。各条件的 MOS 与 95% 置信区间按 BT.500-15 给出。
- 观察者筛除：主分析不筛除。BT.500-15 的峰度法与相关法两种筛除下的结果作为敏感性分析一并报告。

配置键：`screening_primary: "none"`，`alternative: "two-sided"`，`primary_family: ["P1","P2","P3","P4a","P4b","P5"]`，`part1_primary_pair: ["mono","ours"]`，`preference_no_difference_as_zero: true`，`ssq_primary_contrast: ["S_pre","S_post"]`，`correlation_mct: 0.7`，`bootstrap_iterations: 10000`，`bootstrap_seed: 20261115`。

## 3. 次要与描述性分析（不进入上面的检验族）

- Ours 对 DeepSynthesis、Ours 对 MotionParallax 在三项评分上的差：探索性，报告检验结果与置信区间，不做校正，行文中标明为探索性。配置键 `part1_extra_pairs: [["deepsynthesis","ours"],["motionparallax","ours"]]`。
- 第一部分按场景类型（合成室内、真实室内、真实室外）分别给出各条件的 MOS 与差值。
- 第二部分：只在答"有区别"的试次上计算的偏好；按修正半径分组的 d′ 与偏好；逐片段的合并 d′。
- SSQ：四个时间点的 N、O、D、TS，以及开始到第一部分后、休息后到结束、开始到休息后的变化。只报数。
- 改分率、观看时长、注视训练、自然注视范围、头部偏离分布、丢帧：只报数。

## 4. 解释时的约定

- P2、P3 的方向事先不设定。Mono 是未处理的输入，本身没有合成瑕疵，Ours 在"画面瑕疵"上低于 Mono 属于可预期的结果，按实际方向与置信区间报告。
- 检验不显著不写成"没有差别"，只报告差值的置信区间。
- 第二部分若 d′ 与 0 无显著差别，结论写作"在本实验的刺激与观看条件下未检出可分辨的差别"，并给出 d′ 的置信区间。
- SSQ 是整段累积量，两种渲染方式混合呈现，不能归到单一方法。
